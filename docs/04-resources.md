# Resources and Official Links

These links favor official documentation and stable primary sources.

## Application development

- [FastAPI tutorial](https://fastapi.tiangolo.com/tutorial/) - routes, dependencies, validation, security, testing, and deployment.
- [Pydantic documentation](https://docs.pydantic.dev/) - request models, settings, and output validation.
- [SQLAlchemy 2.0 documentation](https://docs.sqlalchemy.org/en/20/) - ORM, async sessions, relationships, and transactions.
- [Alembic tutorial](https://alembic.sqlalchemy.org/en/latest/tutorial.html) - schema migrations.
- [PostgreSQL documentation](https://www.postgresql.org/docs/) - constraints, indexes, JSONB, backup, and performance.
- [React documentation](https://react.dev/learn) - components, state, and application patterns.
- [Vite guide](https://vite.dev/guide/) - React build and development server.
- [Tailwind CSS with Vite](https://tailwindcss.com/docs/installation/using-vite) - current installation workflow.
- [TanStack Query](https://tanstack.com/query/latest/docs/framework/react/overview) - API server state, caching, and mutations.
- [TipTap documentation](https://tiptap.dev/docs/editor/getting-started/overview) - rich text editor integration.

## AI providers

- [OpenAI Responses API](https://developers.openai.com/api/reference/resources/responses/methods/create) - current response creation API.
- [OpenAI Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs) - schema-constrained output for reliable parsing.
- [OpenAI models](https://developers.openai.com/api/docs/models) - choose a current model based on quality, latency, and price.
- [OpenAI pricing](https://openai.com/api/pricing/) - verify costs before fixing a model in configuration.
- [Gemini API documentation](https://ai.google.dev/gemini-api/docs) - API setup and generation.
- [Gemini structured output](https://ai.google.dev/gemini-api/docs/structured-output) - JSON-schema responses.
- [Gemini models](https://ai.google.dev/gemini-api/docs/models) and [pricing](https://ai.google.dev/gemini-api/docs/pricing) - current capabilities and cost.

## Security, testing, and operations

- [OWASP API Security Top 10](https://owasp.org/API-Security/) - authorization, resource access, abuse, and configuration risks.
- [OWASP Password Storage Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html) - Argon2id and password handling guidance.
- [Pytest](https://docs.pytest.org/) and [HTTPX](https://www.python-httpx.org/) - service/API testing.
- [Vitest](https://vitest.dev/guide/) and [Testing Library](https://testing-library.com/docs/react-testing-library/intro/) - frontend unit/component tests.
- [Playwright](https://playwright.dev/docs/intro) - browser E2E testing.
- [Docker Compose](https://docs.docker.com/compose/) - local multi-container environment.
- [GitHub Actions](https://docs.github.com/actions) - CI/CD workflows and secrets.
- [Terraform documentation](https://developer.hashicorp.com/terraform/docs) - infrastructure as code.
- [OpenTelemetry](https://opentelemetry.io/docs/) - traces, metrics, and structured observability.

## Data and UX research

- [YouTube Creator Academy](https://creatoracademy.youtube.com/) - platform content principles and formats.
- [Instagram Creators](https://creators.instagram.com/) - official platform guidance.
- [TikTok Creative Center](https://ads.tiktok.com/business/creativecenter/) - trend and creative research; check usage rights before collecting data.
- [LinkedIn creator resources](https://www.linkedin.com/help/linkedin/topic/a190054) - official publishing help.
- [Google Trends](https://trends.google.com/trends/) - compare search interest manually or through approved access.
- [Kaggle datasets](https://www.kaggle.com/datasets) - optional evaluation data; inspect each dataset license and privacy terms.

Do not scrape a site merely because it is publicly visible. Use official APIs or exported datasets, follow terms and robots rules, preserve attribution, and document the license for every dataset placed in the project.
